# Contributing

Contributions are welcome through GitHub issues and pull requests.

1. Fork the repository and create a focused branch.
2. Install dependencies with `npm install`.
3. Make the change and add or update tests.
4. Run `npm run check` and `npm run build`.
5. Open a pull request explaining the behavior and tradeoffs.

Do not include real phone numbers, group IDs, API keys, WhatsApp session data, or private group messages in issues, fixtures, logs, or commits.
